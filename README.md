# ITBDA4-14 Project 2

Big data and text analytics project covering MapReduce, topic modelling, web text mining and an ETL pipeline into PostgreSQL.

| Folder | Content |
|---|---|
| `q1-mapreduce/` | Java Hadoop MapReduce keyword search (Q1) |
| `notebooks/` | R Markdown notebooks for Q2, Q3 and Q4 |
| `data/` | Raw and cleaned datasets (generated by the notebooks) |
| `sql/` | PostgreSQL schema, import and analytical queries |
| `docs/` | Project documentation and setup notes |

## Reproduce
1. Q1: `cd q1-mapreduce && mvn clean package`, then run as described in its README.
2. Q2 and Q3: place `news.zip` in `notebooks/`, then knit the notebooks.
3. Q4: knit `notebooks/Q4_ETL_scrape_clean_load.Rmd`, then run `psql -d bookstore -f sql/q4_postgres.sql`.

Data sources: books.toscrape.com (scraping sandbox), Eurac Research blog (CC BY 4.0).
